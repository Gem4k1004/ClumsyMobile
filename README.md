# Clumsy Mobile (Android overlay demo)

This project creates a movable floating button with ON/OFF visual state above other apps.
It does **not** manipulate Roblox, network traffic, or gameplay.

## Build
1. Open this folder in Android Studio.
2. Allow Gradle sync.
3. Build > Build APK(s).
4. Install the APK on your Android device.
5. Open Clumsy Mobile, grant "Display over other apps", and tap Start floating button.

The overlay can be dragged. Tap it to toggle its visual state. Stop it from the app.
